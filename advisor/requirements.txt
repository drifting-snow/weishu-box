# ---------------------------------------------------------------------------
# SIZE NOTE for GitHub / offline distribution (measured on win_amd64, py3.11)
# ---------------------------------------------------------------------------
# A plain install pulls opencv-python (~112 MB incl. Qt/GUI + an FFmpeg video
# plugin). Static-image OCR never opens a window or decodes video, so you can
# shrink the stack from ~235 MB to ~204 MB with NO accuracy loss (verified:
# same 4/4 shop cards, identical confidences 0.84-0.999):
#
#   pip install -e ".[vision]"
#   pip uninstall -y opencv-python
#   pip install "opencv-python-headless==4.10.0.84"   # same cv2, no Qt/GUI
#   python tools/slim_vision.py --apply               # removes FFmpeg plugin
#
# rapidocr only ever imports `cv2`, which headless provides. This leaves one
# BENIGN `pip check` metadata note (rapidocr declares opencv-python); runtime is
# unaffected. A fully pip-check-clean path needs the rapidocr 3.x API migration
# (it declares opencv-python-headless natively) - tracked on the roadmap.
